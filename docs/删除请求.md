# 删除请求与联系方式

如果你是相关素材的权利人或其授权代表，希望删除、停止提供、补充署名或更正来源，可以联系仓库维护者：

- **仓库联系入口：** [提交版权或删除请求 Issue](https://github.com/lliooly/wuwa-tappo-assets/issues/new?template=rights.yml)。
- **平台正式投诉：** [GitHub 内容移除请求说明](https://docs.github.com/en/site-policy/content-removal-policies/submitting-content-removal-requests)，其中包含版权投诉入口。

为了便于定位，请尽量提供素材在仓库中的路径或链接、需要采取的措施，以及能够说明权利或授权关系的信息。Issue 是公开的，请不要提交证件、住址、电话号码或其他敏感个人信息；需要提交保密材料时，可使用 GitHub 官方正式流程。

维护者收到请求后会尽快核对，根据情况进行更正、移除或进一步沟通。移除仓库当前文件并不自动删除已有克隆、副本、缓存或 Git 历史；必要时会进一步处理可控范围内的历史记录，并配合 GitHub 的相关流程。
