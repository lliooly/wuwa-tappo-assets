# 目录与命名

```text
assets/
  角色/完整图/        # 角色完整图
  角色/身体分层/      # body_1、body_2、body_3
  角色/头部分层/      # head_1、head_2
  角色/图鉴图/
  配件/素材图/、配件/图鉴图/
  表情/素材图/、表情/图鉴图/
  界面/原版/、界面/登录SDK/
  图标/Windows原生/、图标/发行包/
  字体/
data/
  catalog.json        # 899 个公开图鉴条目及所有文件路径
  files.json          # 仓库实际素材文件和 SHA-256
  aliases.json        # 历史名称到实际文件的映射
  来源快照/           # 原始公开索引及恢复清单
```

角色文件名示例：`role_1102_1001_body_1.png` 表示角色 `1102`、系列 `1001` 的第一张身体分层；该名称和动作编号来自客户端约定，不应根据编号猜测图像语义。图鉴 ID、素材 ID、名称、稀有度、图片尺寸以及原始布局偏移保存在 [catalog.json](../data/catalog.json)。

素材按照文件内容去重。历史名称仍保存在 [aliases.json](../data/aliases.json)，其值是仓库实际文件路径，**不是**需要读取的符号链接。当前快照的表情图鉴图与对应素材图相同，因此图鉴条目直接指向 `表情/素材图`；部分默认素材也指向已有文件。

原始上游地址和 UUID 不用于本仓库的文件命名；它们保留在 [remote-files.json](../data/来源快照/remote-files.json)，用于追溯来源。目录和索引来自特定时点，之后官方新增、修改或不再公开的内容不在此快照范围内。
